How to deliver recordings directly to your Dropbox

Direct Dropbox Folder Delivery

Yes! You can automatically receive recordings in your Dropbox folder using one of two easy options:

  1. Dropbox File Request (Easiest - Recommended): Create a Dropbox File Request in your Dropbox account. Paste the link below. When relatives finish recording, they click "Upload to Dropbox" and it lands right in your folder.
  2. Automated Webhook (Make / Zapier): Connect a Webhook URL from Make or Zapier that instantly saves incoming audio files directly to your Dropbox root folder behind the scenes.

Found under Dropbox > File Requests > Create Request.
